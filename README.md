# 🏆 Achievements Investitore Retail

Un sistema di achievement personalizzato per tracciare i tuoi successi come investitore retail, simile a Steam.

## 🚀 Come Usare

1. Apri il file `index.html` nel tuo browser
2. Naviga tra le categorie usando i pulsanti in alto
3. Clicca sulla checkbox per marcare un achievement come completato
4. I tuoi progressi vengono salvati automaticamente nel browser (localStorage)

## 📊 Categorie Achievement

- **💰 Guadagni**: Traccia i tuoi guadagni da singoli titoli e portafoglio totale
- **📈 Performance**: Raggiungi obiettivi di performance come +100%, +200%, ecc.
- **💳 Dividendi**: Traccia i tuoi guadagni da dividendi
- **🎯 Milestone**: Traccia i traguardi importanti della tua carriera
- **🎓 Strategia**: Riconosci le diverse strategie di investimento che usi

## 🎨 Caratteristiche

- ✅ 50 achievement unici e personalizzati
- 🎨 Design moderno e responsive
- 💾 Salvataggio automatico dei progressi
- 🏷️ Sistema di rarità (Common, Rare, Epic, Legendary)
- 📱 Compatibile con dispositivi mobili
- 🎯 Statistiche in tempo reale

## 🔧 Personalizzazione

Puoi modificare gli achievement nel file `achievements.js` per aggiungere o modificare i tuoi obiettivi personali.

## 📝 Note

- I dati vengono salvati localmente nel tuo browser
- Per resettare tutti gli achievement, apri la console del browser e esegui: `resetAll()`
